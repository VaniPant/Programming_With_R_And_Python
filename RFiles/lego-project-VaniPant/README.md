# Lego Project

This repository contains my R Project for the **MADS-4** course, **Programming with R and Python**. I have created an R script to automatically download the LEGO files from the website *https://rebrickable.com/downloads/* and implemented all the solutions to the questions provided on the course page *https://r-training.pages.uni.lu/mads-r-py/projects/lego.html*.
